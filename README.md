# Brew & Bean Coffee Shop Website

A multi-page website for Brew & Bean Coffee Shop built using HTML, CSS, and JavaScript, version-controlled with Git/GitHub, and deployed via GitHub Pages.

## Live Links
- **Live Website URL:** https://talhaj08.github.io/brew-and-bean-coffee-shop/
- **GitHub Repository URL:** https://github.com/talhaj08/brew-and-bean-coffee-shop

## Pages & Features
- **Home (`index.html`):** Welcome section, coffee shop hero image, interactive menu table with item selection alerts, and an "Order Now" button.
- **Gallery (`gallery.html`):** Showcase grid of freshly brewed coffees and baked snacks.
- **Contact (`contact.html`):** Store location, hours, contact details, and an interactive pre-order/inquiry form with confirmation alerts.
- **Shared Styling & Interactivity (`style.css`, `script.js`):** Consistent warm coffee-themed design across all pages and JavaScript event handlers.
